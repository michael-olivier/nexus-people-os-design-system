About the Design System

Nexus People OS Design System packages tokens, UI primitives, and writing guidance extracted from the Career Coach Agent prototype—and expands them for the broader agent portfolio.

What it covers

  • Foundations — Color, typography, icons, content, and in-product messages.
  • Components — Brand, buttons, forms, panels, status pills, and agent icons.
  • Tooling — CSS bundle build, Figma spec export, and this documentation site.

Source of truth

Design tokens live in tokens/tokens.css. Component styles are partials under components/, concatenated into dist/nexus-ds.css. Product teams should consume the bundle rather than fork one-off styles per app.

Contributing

Propose changes in the GitHub repository. Keep prototypes and this site in sync when you add or rename tokens and classes.
