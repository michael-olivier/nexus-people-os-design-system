Get started

Overview

Add Nexus People OS styles to a static HTML app or prototype shell.

Install the CSS bundle

Clone this repository or copy dist/nexus-ds.css into your project.

Fonts & icons

Load Inter (300/400) and Lucide from assets/vendor/lucide.min.js (synced via npm run icons:sync). Browse every icon on the Icons page.

Build from source

Terminal 
npm run build      # dist/nexus-ds.css
npm run build:site # documentation gallery → site-dist/

Integrate with Career Coach Agent

See integration guide for migrating the prototype off monolithic styles.css.
