Get started

Develop

Consume the bundled CSS, sync icons, and run the documentation site locally when you change tokens or components.

Repository scripts

Terminal 
npm install
npm run build          # dist/nexus-ds.css from partials
npm run icons:sync     # lucide.min.js → assets/vendor/
npm run build:site     # site-dist/ documentation
npm run dev:site       # build + serve on :8770

Using components

Class names match the previews under Components. Load dist/nexus-ds.css once, then apply the documented markup.

  • Call lucide.createIcons() after DOM updates for icon buttons and pills.
  • Override sparingly—extend tokens in tokens/tokens.css when possible.

Documentation site

Content pages live in website/content/ and compile via scripts/build-website.mjs. Add a page entry in that script and website/nav.json when you introduce new docs.

Code blocks use <pre class="ds-code"><code class="language-…"> and are colorized at build time. See website/content/_snippet-reference.html for the terminal snippet pattern.
