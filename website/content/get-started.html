Get started

Add Nexus People OS styles to a static HTML app or prototype shell.

Install the CSS bundle

Clone this repository or copy dist/nexus-ds.css into your project.

<link rel="stylesheet" href="./design-system/nexus-ds.css" />

Fonts & icons

Load Inter (300/400) and Iconoir — components assume iconoir-* classes.

<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400&display=swap" rel="stylesheet" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/iconoir@7.12.1/css/iconoir.css" />

Build from source

npm run build      # dist/nexus-ds.css
npm run build:site # documentation gallery → site-dist/

See integration guide for migrating the prototype off monolithic styles.css.
